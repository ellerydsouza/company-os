# Weekly update template

Post in the team channel, same day each week. Ten lines or fewer, a link
on every item, facts only. See [RFD 0013](../../rfd/0013/README.md) and the
[operating cadence](../operating-cadence.md).

```
Week of YYYY-MM-DD

Shipped
- <what merged, deployed, or closed> (<link>)

In progress
- <what is underway and where it stands> (<link>)

Blocked / need
- <the fact>: <the ask> (<link>)

Next week
- <what you intend to ship>
```

Skipping a week: post "no update this week: <reason>" instead of nothing.
